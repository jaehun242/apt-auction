# 법원경매 데이터 소스 조사 기록

조사·검증일: 2026-09-02 (Asia/Seoul)

## 확인 결과

- 대한민국 법원경매정보 공개 화면은 `https://www.courtauction.go.kr/pgj/index.on`에서 WebSquare 기반으로 제공된다.
- 공개 화면 정의 `PGJ151M01.xml`에서 물건상세검색 제출 경로 `/pgj/pgjsearch/searchControllerMain.on`, JSON 입력 맵 `dma_pageInfo`와 `dma_srchGdsDtlSrchInfo`, 결과 목록 `dlt_srchResult`를 확인했다.
- 아파트 용도 코드는 화면 정의 기준 `20000 > 20100 > 20104`이며 표시 용도명은 `아파트`다.
- 소재지 시도코드 `11`(서울), `26`(부산)의 실제 응답에서 HTTP 200, `ipcheck: true`, 사건번호·법원·주소·가격·기일·유찰횟수를 확인했다.
- 날짜 공란 검색은 2026-09-21 예정인 부산 2025타경684를 반환하지 않아 전체 진행 물건 조회로 사용할 수 없었다. 2026-09-17~10-01 구간 검색에서는 해당 사건이 진행 `Y`, 매각기일 2026-09-21로 반환됐다.
- 법원 화면은 부동산 매각기일 검색을 최대 14일로 제한한다. 한 번에 큰 기간을 요청하지 않고 실행일~90일을 14일 이하의 겹치지 않는 7개 구간으로 나눠 수집한다.
- 공공데이터포털 검색에서는 사건별 법원경매 공식 Open API를 확인하지 못했고, 감정평가사협회 통계성 연계 데이터만 확인했다. 따라서 본 프로젝트는 검증된 공개 검색 요청을 저속으로 사용한다.

## 수집 원칙

- 하루 1회, 요청 사이 450ms 간격, 지역·구간별 최대 20페이지로 제한한다.
- CAPTCHA, 로그인, 로봇 탐지 또는 접근 제한을 우회하지 않는다. `ipcheck`가 true가 아니면 즉시 실패한다.
- 법원 결과의 대·중·소 용도 코드와 용도명이 모두 정확히 아파트인 행만 사용한다.
- `법원코드 + 내부사건번호 + 물건번호`로 그룹화하고 집합건물 대표 행 한 건만 저장한다. 같은 사건의 다른 물건번호는 별도 물건으로 유지한다.
- 필수 필드가 없거나 지역코드가 요청 지역과 다르면 자동 게시하지 않고 검토 제외한다.
- 수집 범위 확대 시 처음 발견한 기존 진행 물건은 backfill로 표시해 이번 주 신규 통계에서 제외한다.
- 안정적으로 검증하지 못한 사건별 원문 문서 URL은 만들지 않는다.

## 네이버 Geocoding

- 공식 엔드포인트 `https://maps.apigw.ntruss.com/map-geocode/v2/geocode`와 서버 헤더 `x-ncp-apigw-api-key-id`, `x-ncp-apigw-api-key`를 사용한다.
- Client Secret은 GitHub Actions의 Repository Secret에서만 읽고 프런트 번들에는 전달하지 않는다.
- 주소별 결과를 `data/geocode-cache.json`에 캐시한다. 캐시 미등록 주소만 요청하고 실패한 주소도 물건 목록에서 제거하지 않는다.

## 운영상 한계

- 공개 화면용 요청은 정식 사건 데이터 Open API가 아니므로 법원 화면 개편 시 스키마가 바뀔 수 있다.
- 현재 수집 지평은 실행일 포함 90일이며, 그보다 뒤에 기일이 잡힌 물건은 다음 일일 실행에서 범위 안으로 들어올 때 수집된다.
- 권리·점유·체납관리비·실거래가와 사건별 원문 문서는 연동하지 않았다. 모두 확인 필요로 표시한다.
