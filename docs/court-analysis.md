# 법원 원문 기반 1차 자동분석

검증일: 2026-09-03 (Asia/Seoul)

## 사용 범위

- 사건·물건 상세정보와 현황조사서의 실제 JSON 응답만 사용한다.
- 매각물건명세서 뷰어 발급 요청과 감정평가서 직접 URL은 안정적으로 접근되지 않아 저장하거나 링크하지 않는다.
- 등기부, 배당표, 체납관리비는 수집·추정하지 않는다.
- 개인 이름, 주민등록번호, 감정평가 담당자 이름은 캐시와 공개 JSON에 저장하지 않는다.

## 구조화 필드

- 최선순위 설정일자 참고정보
- 매각 후 존속권리 관련 기재와 특별매각조건·물건 비고
- 점유 형태와 점유조사 내용
- 임차인·점유관계인의 점유부분, 용도, 점유기간, 전입일, 확정일, 보증금, 월세
- 배당요구 여부는 확인 가능한 응답 필드가 없으면 `확인 필요`

## 분석 원칙

- 전입일과 최선순위 설정일자가 모두 있을 때만 선후를 비교한다.
- 이전 전입은 대항력·인수 가능성의 추가 확인 신호로만 표시한다.
- 폐문부재, 점유 불명, 핵심 날짜 누락은 `확인 필요`로 낮춘다.
- `안전`, `선순위 임차인 확정`, `인수금액 0원` 같은 확정 표현을 사용하지 않는다.
- 인수예상은 `추가 인수금액 현재 자료에서 확인되지 않음`, `임차보증금 인수 가능성 있음 — 추가 확인 필요`, `자동 산정 불가` 중 하나만 사용한다.

## 캐시

`data/document-cache/documents.json`은 `법원코드 + 사건번호 + 물건번호`별 분석 결과를 보존한다. 기일·최저가·유찰횟수·진행상태가 같으면 정상 또는 부분 분석을 재사용한다. `UNAVAILABLE` 항목은 다음 실행에서 재시도하며, 일시적인 법원 오류가 발생해도 기존 정상 분석은 삭제하지 않는다.
